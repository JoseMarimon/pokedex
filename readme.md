# Tutorial: Creación de Cuenta en Azure for Students

Para el alojamiento de este proyecto, se utilizó la nube pública de Microsoft Azure, específicamente aprovechando el beneficio para estudiantes. A continuación, el paso a paso de su creación:

1. **Acceso al portal:** Ingresar a la página oficial de [Azure for Students](https://azure.microsoft.com/es-es/free/students/).
2. **Inicio del proceso:** Hacer clic en el botón "Empiece gratis" (Start Free).
3. **Autenticación Institucional:** Iniciar sesión utilizando el correo electrónico institucional de la universidad, el cual está vinculado a los servicios educativos de Microsoft.
4. **Verificación de identidad y estado académico:** 
   * Completar el formulario con los datos personales.
   * Realizar la verificación de identidad mediante un código enviado por SMS al teléfono móvil.
   * El sistema valida automáticamente el dominio educativo del correo para aprobar el estatus de estudiante sin necesidad de registrar una tarjeta de crédito.
5. **Aceptación de términos:** Aceptar el acuerdo de suscripción de Microsoft y la declaración de privacidad.
6. **Configuración final:** Al finalizar, el sistema redirige al portal principal de Azure (portal.azure.com), otorgando 100 USD en créditos y acceso a servicios gratuitos, como las **Static Web Apps** que usaremos para la Pokedex.
